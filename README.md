## 👨‍💻 About Me

I'm a **Frontend Developer** focused on building modern, responsive, and scalable web applications using **React.js, Next.js, TypeScript, Redux Toolkit, and TailwindCSS**.

I also work with **React Native and Expo** to build cross-platform mobile applications, while continuously expanding my knowledge in backend development with **Node.js, Express.js, and databases**.

My development interests include:

- 🎨 Modern Frontend Development
